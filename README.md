# Quiz bot

Бот на aiogram 3, который принимает компактный формат опросов, хранит их в SQLite и запускает задания в отдельном сообщении. Основное меню редактируется, а не засоряет чат новыми сообщениями; текст с новым опросом удаляется после успешного импорта. В каждом раунде вопросы выбираются случайно без повторов; в конце бот показывает результат и предлагает завершить либо начать новый раунд.

## Запуск

Выполняйте команды из корня репозитория. Код использует синтаксис Python 3.10+. Создайте бота через @BotFather и сохраните его токен в локальном файле `.env`.

### Windows (PowerShell)

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Откройте `.env` в текстовом редакторе и замените значение `BOT_TOKEN` токеном своего бота. Если `.env` уже настроен, сохраните его вместо повторного копирования шаблона. Затем запустите:

```powershell
.\.venv\Scripts\python.exe bot.py
```

### Linux / macOS

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
```

Укажите токен в `.env` так же, как описано выше, затем запустите:

```bash
.venv/bin/python bot.py
```

### Настройки и данные

Переменная окружения `BOT_TOKEN`, если она уже задана, имеет приоритет над значением из `.env`. Не публикуйте настоящий токен: `.env` исключён из Git, а `.env.example` служит только шаблоном.

При запуске автоматически создаётся `quizzes.sqlite3` в текущей рабочей папке процесса. При запуске из корня репозитория база будет рядом с `bot.py`. В базе хранятся импортированные опросы; перед переносом или резервным копированием файла остановите бота.

После запуска откройте своего бота в Telegram и отправьте `/start`.

## Формат опроса

Название задаётся строкой `@ ...`; темы — строкой `# ...`. Подсказка необязательна.

```text
@ Животные и английские слова

# Животные
|Кто мяукает?|[кот]
|Кто лает?|[собака]
|Кто говорит «му»?|[корова]{Сельскохозяйственное животное}
\Выбери животных\[кот;собака]{Домашние питомцы}

# English words
/Переведи: собака/[dog]{Животное, которое лает}
/Переведи: кошка/[cat]
/Переведи: корова/[cow]
```

`|...|[...]` — выбрать один из трёх вариантов. `/.../[...]` — написать один ответ вручную. `\...\[a;b]` — выбрать несколько вариантов и подтвердить. Неверные варианты бот берёт из ответов той же темы (в том числе из других опросов), а затем — из любых сохранённых заданий.

Для удаления: `/delete Животные и английские слова`.

## Заметка

Для заданий с кнопками в опросе должны быть другие уникальные ответы: два для обычного выбора и `3 - число верных` для множественного. Бот проверяет это перед стартом и не запускает некомплектный опрос.
