# Quiz bot

Бот на aiogram 3, который принимает компактный формат опросов, хранит их в SQLite и запускает задания в отдельном сообщении. Основное меню редактируется, а не засоряет чат новыми сообщениями.

## Запуск

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:BOT_TOKEN = "токен_бота_из_BotFather"  # либо создайте .env: BOT_TOKEN=...
py bot.py
```

Рядом с `bot.py` автоматически появится `quizzes.sqlite3`.

## Формат опроса

Название задаётся строкой `@ ...`; темы — строкой `# ...`. Подсказка необязательна.

```text
@ Животные и английские слова

# Животные
|Кто мяукает?|[кот]
|Кто лает?|[собака]
|Кто говорит «му»?|[корова]{Сельскохозяйственное животное}
\Выбери животных\[кот;собака]{Домашние питомцы}

# English words
/Переведи: собака/[dog]{Животное, которое лает}
/Переведи: кошка/[cat]
/Переведи: корова/[cow]
```

`|...|[...]` — выбрать один из трёх вариантов. `/.../[...]` — написать один ответ вручную. `\...\[a;b]` — выбрать несколько вариантов и подтвердить. Неверные варианты бот берёт из ответов той же темы (в том числе из других опросов), а затем — из любых сохранённых заданий.

Для удаления: `/delete Животные и английские слова`.

## Заметка

Для заданий с кнопками в опросе должны быть другие уникальные ответы: два для обычного выбора и `3 - число верных` для множественного. Бот проверяет это перед стартом и не запускает некомплектный опрос.
